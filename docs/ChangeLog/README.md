## 变更记录规则

1. 设计基线保留原始正文；状态澄清通过显式注释或新修订记录补充，避免改写历史。
2. 工程记录按日期列出新增、修复、兼容性/迁移、验证证据、未完成项和提交范围。尚未提交的实现标为“工作区”，未验收的版本不能标为正式发布。
3. 发布后补充应用版本、实际提交号/标签和验证结果。文档提交号不等于代码发布提交号。
4. 两个仓库的三份共同设计文档及本索引保持一致；各自工程记录、运行说明与验证记录由对应仓库维护。
5. 新版本只记录相对上一版本的变化，设计目标与实测结果分别描述，不把计划指标写成已达成指标。

本仓库具体记录见 [工程变更记录](CHANGELOG.md)，验证证据见 [VALIDATION](../VALIDATION.md)。
