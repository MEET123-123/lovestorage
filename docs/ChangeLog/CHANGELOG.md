# 2026-10-03 — 0.3.0 本地候选版（未发布）

- 前端：注册/登录/退出/改密、账号本地分库、完整备份与空库事务恢复、文本候选与歧义提示。
- 后端：Spring Security 与 PBKDF2、12 小时可撤销会话、owner_id 隔离、Flyway V2/V3、版本条件备份、文本识别 API、数据库健康检查。
- 算法：中文/全角/MFG/EXP 日期、无效日期过滤、多候选冲突、共同 12 组样例；不推测缺失日期，不自动创建库存。
- 兼容性：匿名库存接口现在返回 401；历史无主记录保留并隔离；原核心字段上传与完整快照并存。
- 验证：后端 8 个测试方法、前端 41 项检查、两端共享规则、真实 PostgreSQL HTTP 联调、应用与测试 HAP 编译通过。原生设备和公网验收尚未完成。
- PostgreSQL 新版运行于独立 smart_expiry_candidate 库，本机端口 18081；运行步骤和限制见 [本地候选版说明](../LOCAL_CANDIDATE.md)。

## 未发布 — 客户端 0.2.0（2026-10-03 工作区已实现）

### 新增与改进

- 首页、物品、建议、我的四个主入口，独立编辑、详情、统计页面。
- 品牌、数量单位、生产日期、保质期、开封期限、位置、备注和提醒提前天数；支持自然日期校验及有效到期日预览。
- 搜索、分类/状态筛选、排序、用完/丢弃/归档/恢复、软删除、稍后处理。
- 处理流水与撤销、按记录统计、规则建议、补货清单和明确标签的文本辅助录入。
- 系统提醒权限及计划适配；最多注册最近 20 条未来计划，失败提示不阻断本地保存。

### 数据与兼容性

- 客户端数据库 v1 → v2：增加物品元数据、批次、处理流水和补货清单；旧数据保留身份、到期日与同步状态。
- 当前每物品一批次；恢复操作撤销有效处理记录，软删除保留历史。
- HTTP 上传数量、单位和有效到期日；品牌、原始开封信息、位置、备注、提醒配置、流水和补货清单仍只保存在本地。
- 覆盖安装用于升级验证；卸载会清除本地数据。旧程序读取 v2 数据的降级兼容性未验证。

### 验证与已知限制

- 已记录通过：22 项主机业务/存储检查、9 条共享日期 fixture、2 条日历边界检查、实际后端 HTTP 联调、应用及测试 HAP 编译。
- HAP 未签名；没有连接设备，未执行设备 UI、原生 ArkData、Hypium 和实际提醒触发测试。
- 待实现：多批次、部分消耗、自定义分类、OCR、语音、完整同步。后续次序和验收项见前端细化规格 17.9–17.10。
