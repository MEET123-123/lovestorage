# 0.4.0 本地候选版：登录、个人资料、完整备份与规则识别

日期：2026-10-03。目标是先在本机跑通用户隔离和完整数据备份，并让前后端日期识别遵守共同样例。该版本未完成商店上架或公网生产验收。

## 交付范围

| 部分 | 本轮新增 | 边界 |
|---|---|---|
| 后端账号 | 用户名注册、登录、当前账号、退出、修改密码 | 用户名 3–32 位字母数字下划线，大小写不敏感；密码 12–64 字符；暂未提供找回密码/注销账号 |
| 登录方式与资料 | 账号密码；`local-sms` 本地调试验证码；按账号读写昵称、头像、忌口与偏好 | 调试码不发送短信也不验证号码归属；华为 App ID/签名及服务端授权未配置；饮食提示不能替代包装过敏原检查 |
| 身份安全 | Spring Security、PBKDF2 密码散列、随机 Bearer 会话 | 令牌有效 12 小时，数据库只保存其 SHA-256；改密撤销全部会话；认证写请求每来源 IP 每分钟最多 30 次，单进程限流 |
| 数据隔离 | 每个物品绑定 owner_id；列表、读取、更新、删除和重试都检查账号 | V1 历史无主记录保留但不对新用户开放；没有自动“认领历史数据”入口 |
| 前端账号 | 启动独立登录页；按用户 UUID 分本地库；个人中心编辑账号资料 | 令牌与密码不落盘；应用重启后需重新登录；个人资料按账号保存 |
| 完整备份 | 物品全字段、软删除记录、处理流水、补货清单 | 用户显式触发；含原始开封日期、备注与位置；不含凭据、服务器配置和设备提醒偏好 |
| 恢复与冲突 | 空账号库存事务恢复；备份 revision 条件写入 | 本地已有任何物品/历史/清单时拒绝恢复；旧 revision 返回 409；尚非双向增量同步或自动合并 |
| 识别算法 | 中文日期、全角字符、MFG/EXP、保质期、候选依据与冲突警告 | 只处理文本，不调用 OCR、ASR 或大模型；最多 2000 字；不猜缺失年份；必须人工保存 |
| 运行保障 | 数据库参与健康检查、503 故障反馈、优雅停机、统一错误状态 | 尚无生产监控、跨实例限流、容灾或容量验收 |

## 本机运行

### 独立 H2 文件数据库

在后端仓库运行：

```powershell
.\scripts\build.ps1
.\scripts\run.ps1 -Profile local -Port 18081
```

数据位于 `data/smart_expiry`。如果已有进程打开同一个文件库，先停止那个进程再启动。JAR 名为 `target/smart-expiry-server-0.4.0-local.jar`。

本地验证码需显式启用，并且只适合可信的本机调试环境：

```powershell
.\scripts\run.ps1 -Profile local -LocalSms -Port 18081
```

该命令用 H2 文件数据库，不需要 Docker。验证码会通过接口响应返回给客户端，不会发送短信；不要在公网环境启用 `local-sms`。

### PostgreSQL 联调库

0.3.0 历史联调使用现有 Docker PostgreSQL 中的独立数据库 `smart_expiry_candidate`，保留原 `smart_expiry` 数据库。0.4.0 本轮没有可用 Docker/数据库服务，新增接口通过 H2 随机端口集成测试验证。

IDEA 运行 `SmartExpiryApplication` 的环境变量：

```text
SPRING_PROFILES_ACTIVE=default
SERVER_PORT=18081
DB_URL=jdbc:postgresql://localhost:5432/smart_expiry_candidate
DB_USERNAME=smart_expiry
DB_PASSWORD=smart_expiry
```

以上凭据是项目原有本地默认值；自定义过的环境应填写自己的配置。Docker 后端 18080 与 IDEA/本机 Java 18081 是不同进程，更新 JAR 不会自动更新正在运行的旧容器。

健康检查：`GET http://localhost:18081/api/v1/health`。健康接口无需登录，会执行数据库查询。

### 前端

使用 DevEco 打开 `append/harmonyos`，配置签名与设备后运行。应用启动后会显示独立登录页；先在登录页“本地接口调试”中填写电脑局域网地址并测试连接（真机不能填 localhost），再用用户名/密码注册或登录。进入首页后，“我的”可编辑头像、昵称、个人简介、忌口和偏好，并可再次检查本地接口、同步和备份。

登录后按账号使用独立本地库；退出后回到登录页。账号本地库会保留，切换账号时不会混读。当前没有访客库存迁入账号的功能。手机号登录只有启用 `local-sms` 后才能用界面显示的调试码；华为登录明确显示未配置。

## Postman

重新导入 `postman/LoveStorage.postman_collection.json` 和 `IDEA.postman_environment.json`，选择 IDEA 环境，确认 `baseUrl=http://localhost:18081`。

1. 首次运行 `00A 首次注册并登录`。环境没有用户名/密码时，会生成本地测试凭据；响应自动写入环境的 `accessToken`。
2. 已有账号运行 `00B 已有账号登录`，无需再次注册。`00C` 核对当前账号。
3. `00D` 查看手机号与华为登录配置；`13A`、`13B` 更新并读取当前账号个人资料。
4. 物品、分类、个人资料、完整备份和文本识别继承集合 Bearer 配置；不再是匿名接口。
5. `11` 仅生成识别草稿，不创建物品；`12` 查询当前账号备份；最后运行 `13` 撤销当前会话。
6. 401 表示需重新登录；404 也用于隐藏其他账号的物品；409 表示用户名重复或备份版本冲突；429 按 Retry-After 等待。

备份保存示例：`PUT /api/v1/backup`，body 含 `expectedRevision` 与 `payload`。payload 是 JSON 字符串，其中 `schemaVersion=1`、`items/records/shopping` 为数组。首次 revision 为 0，每次成功后保存响应中的新 revision；遇到 409 不自动覆盖。字段与响应结构以 OpenAPI 为准。

## 数据迁移与兼容性

- Flyway V1 保持原样，V2 新增用户/会话与物品所有者，V3 新增按账号保存的完整备份表，V4 新增用户资料和认证身份表。
- 旧前端匿名上传在新版后端返回 401，应先更新并登录。不要通过关闭认证兼容旧客户端。
- 原“同步上传”仍为物品核心字段投影；“备份全部库存与记录”另行保存完整快照，两者用途不同。
- 完整快照最多 500000 字符，各数组最多 10000 项。恢复前校验数据，任何条目失败回滚整个恢复；新版本格式需显式迁移，不能静默忽略。
- 设备数据库版本仍为 2；账号分库复用同一迁移。前端版本为 0.4.0 / versionCode 4；应用启动后先显示独立登录页，登录后按用户 UUID 切换本地库。
- 后端新迁移为增量结构，但旧服务没有身份隔离。升级后不要把旧服务作为公网回滚方案。

## 算法验收

两端 `shared/recognition-test-cases.json` 共 12 个固定样例，覆盖中文/全角/英文标签、闰年、无标签日期、多候选、重复候选、倒置日期和超长保质期。Java 与 ArkTS 分别执行同一批预期值。

候选 confidence=0.95 表示明确日期标签的规则强度，不是实测识别准确率。没有采集真实包装评测集，因此不能宣称达到设计文档中的 95% 日期识别指标。
